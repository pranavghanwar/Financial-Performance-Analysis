# Financial Performance Analysis | Python, SQL & Power BI

## Project Overview

This project analyses the financial performance of three major US companies — Apple (AAPL), Microsoft (MSFT), and Walmart (WMT) — from 2013 to 2016.

The objective is to evaluate revenue, profitability, and annual growth using Python for data processing, SQL for financial data queries, and Power BI for interactive business intelligence reporting.

## Tools and Technologies

- **Python:** Pandas and Matplotlib
- **SQL:** SQLite database and financial queries
- **Power BI:** Interactive dashboard, DAX measures, and slicers
- **Data Source:** Kaggle NYSE Financial Dataset
- **GitHub:** Version control and project portfolio

## Project Workflow

1. Imported and explored financial data using Python and Pandas.
2. Created an SQLite database for financial information.
3. Used SQL queries to examine company financial performance.
4. Calculated revenue, net income, profit margins, return on assets, and annual revenue growth.
5. Created financial visualisations using Matplotlib.
6. Built an interactive Power BI dashboard with KPI cards, charts, and filters.

## Financial Dashboard Results

The following results represent the combined dataset across 2013–2016.

| Financial KPI | Result |
|---|---|
| Total Revenue | Approximately $3.06 trillion |
| Total Net Income | $312.62 billion |
| Net Profit Margin | 10.22% |
| Average Annual Revenue Growth | 4.49% |

## Key Findings

- Walmart generated the highest annual revenue among the three companies.
- Apple demonstrated strong profitability relative to revenue.
- Microsoft showed substantial financial performance across the period.
- Revenue growth varied between companies and financial years.
- The interactive dashboard enables company-level and year-level comparisons.
